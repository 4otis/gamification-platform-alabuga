# Алабуга Космос — геймификационная платформа
Геймификационная платформа для мотивации сотрудников и кандидатов **ОЭЗ «Алабуга»**. Проект оформлен в космической тематике и включает мини-игры, систему прогресса и интерфейс платформы.
## О проекте
Платформа задумана как инструмент вовлечения: пользователи выполняют миссии, прокачивают компетенции, зарабатывают очки и открывают награды. Сейчас в качестве основного экрана запускается игра **«Космический рекрутер»** — симулятор проверки кандидатов на космическом корабле.
### Игра «Космический рекрутер»
Вдохновлена механикой проверки документов (в духе *Papers, Please*):
1. Кандидат подходит к вам — **нажмите на персонажа**, чтобы открыть планшет с анкетой.
2. Изучите данные: имя, возраст, планету рождения, должность, обязанности, хобби, контакты.
3. Ищите **анomalies** — невозможные даты, странные имена, несоответствие должности и обязанностей и т.д.
4. Примите решение:
   - **✓ (галочка)** — нанять кандидата (если это человек).
   - **✗ (крест)** — отклонить (если это мимик).
5. За правильное решение +100 очков, за ошибку −50. Статистика отображается в правом верхнем углу.
Часть кандидатов — **мимики**, замаскированные под людей. После решения мимик может показать истинный облик.

## Быстрый старт
### 1. Frontend
```bash
cd frontend
npm install
npm run dev
```
Приложение откроется по адресу: **http://localhost:3000**
### 2. Сборка для production
```bash
cd frontend
npm run build
npm run preview   # предпросмотр production-сборки
```
### 3. Backend (когда будет реализован)
```bash
cd backend
make init   # запуск Docker-контейнеров
make run    # запуск Go-сервера
```
> Backend сейчас содержит только заготовки пакетов. Точка входа `cmd/main.go` и `go.mod` ещё не добавлены.
